# 화면 용어

| 쓰는 말 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| 에이전트 작업 | Claude Code·Codex 등이 worktree에서 하는 일 하나 | 태스크, 세션(단독) |
| 지시 | 에이전트 작업에 보낸 글. 시작할 때의 "처음 지시"(새 작업 창의 지시문)와 그 뒤의 "이어서 보낸 지시"가 있다. 작업 상세의 "지시" 탭이 시각 순으로 보이고, 이어서 보낸 지시마다 "전달됨" · "보내는 중" · "전달 확인 안 됨"을 붙인다. 항목마다 [복사]가 있고 닫힌 작업에서도 보이며, 이 탭은 아무것도 보내지 않는다 | 프롬프트, 메시지 |
| 같은 지시로 새 작업 | 작업 상세 위쪽의 단추(열린·닫힌 작업 모두, [새 창으로] 연 상세에는 없다). 그 작업의 처음 지시와 프로젝트를 채운 새 작업 창을 연다. 제목·도구·기준 브랜치·작업 폴더는 평소 기본값이고, [시작]을 눌러야 시작한다 | 복제, 다시 실행 |
| 작업 폴더 열기 | 작업 상세 [더 보기]의 [VS Code로 작업 폴더 열기](Windows 앱에서만)와 [작업 폴더 터미널]. 작업 폴더가 있는 열린 작업에만 보이고, 터미널은 그 폴더에서 새 창으로 열린다 | worktree 열기 |
| 작업 | `devbox.toml`의 `[[task]]` 한 번 실행하는 명령 | 잡, 런 |
| 서비스 | 계속 떠 있는 실행(`[[service]]`) | 데몬(사용자 화면에서) |
| 예약 | 정해진 시각에 작업을 실행하는 규칙 | 스케줄 잡 |
| 실행 | 작업·서비스를 한 번 돌린 것 | run, receipt |
| 정의 없는 실행 | 정의가 없어진 뒤에도 도는 서비스 실행(설정에서 지움, 브랜치 전환, 이름 변경). 실행 목록의 서비스 아래에 [로그]·[중지]만 있다 | 고아 실행, orphan |
| 진행 작업 | 오래 걸리는 데몬 작업(설치·색인 등) | operation |
| 작업 폴더 | git worktree | 워크트리(본문 설명 외) |
| 데몬 | WSL 안의 devbox 백그라운드 프로그램(진단·설정 화면, 연결 상태 표시·오류 안내 포함. 연결 화면에는 쓰지 않는다) | agent, suite |
| 연결 | 앱과 데몬의 연결 | 세션, 핸드셰이크 |
| 목록 접기·펴기 | 에이전트·터미널·실행·노트·도구 섹션 왼쪽 목록을 접거나 다시 펴는 것(Ctrl+Shift+B, 명령 팔레트의 같은 이름). 접힌 목록 자리의 단추는 [목록 펼치기]다. 폭이 모자라 저절로 접힌 목록은 폭이 넉넉해지면 다시 펴지고, 직접 접은 목록은 그대로 둔다 | 사이드바 |
| 요청 | API 도구에서 보내는 HTTP 요청 하나(`*.request.json` 파일 하나) | 리퀘스트 |
| 컬렉션 | 요청 파일을 모아 둔 곳(개인 컬렉션·프로젝트 컬렉션) | 워크스페이스(단독) |
| 환경 | 요청이 `{{이름}}`으로 쓰는 변수 묶음(`env/<이름>.json`) | 프로필 |
| 비밀 참조 | 이 PC 비밀을 가리키는 `{{secret:이름}}`. 파일에는 값 대신 이것만 둔다 | 시크릿 토큰 |
| 가린 값 | 저장할 때 `[REDACTED]`로 바꾼 직접 입력 비밀. 다시 입력해야 보낸다 | 마스킹, 레닥트 |
| 실행기 | 컬렉션의 요청을 순서대로 보내고 검사·캡처하는 도구 | 러너 |
| 캡처 | 응답에서 꺼내 다음 요청이 쓰는 값 | 추출 변수 |
| 실시간 연결 | API 도구의 WebSocket·SSE 연결 하나(앱↔데몬 "연결"과 구분해 이 이름으로 쓴다) | 세션, 소켓 |
| MCP 서버 | API 도구가 연결해 도구·리소스·프롬프트를 쓰는 서버(stdio 명령 또는 HTTP 주소). 연결 하나도 "실시간 연결"과 같이 [연결 열기]·[연결 닫기]로 다룬다 | MCP 세션, 호스트 |
| gRPC 파일·MCP 파일 | 컬렉션의 `*.grpc.json`·`*.mcp.json` 연결 정의. 프로젝트 파일은 [검토하고 사용] 전에는 쓰지 않는다 | 프로필 |
| 노트 | vault(기본 `~/notes`)의 Markdown 파일 하나 | 메모 파일 |
| 일일 기록 | 날짜별 노트(`daily/YYYY-MM-DD.md`). "오늘 한 일" 요약이 PC 이름 소제목 아래에 들어간다 | 데일리 노트, 저널 |
| 빠른 캡처 | 전역 단축키로 연 작은 창에서 inbox에 한 줄을 남기는 것 | 퀵 캡처, 빠른 메모 |
| 활동 기록 | Windows 앞 창(앱·제목)을 개인정보 규칙대로 모은 시간 기록 | 활동 로그, 트래킹 |
| 휴지통 | vault 안 `.trash/` 폴더. 노트를 지우면 여기로 옮기고 10초 동안 되돌릴 수 있다 | 삭제됨, 쓰레기통 |
| 백링크 | 이 노트를 `[[링크]]`나 Markdown 링크로 가리키는 다른 노트 | 역링크, 참조됨 |
| 앱 업데이트 | Windows 앱 자신의 새 버전 확인·다운로드·설치(설정 → 정보). prod 정식 버전에서만 켜진다 | 자동 업데이트(단독), 패치 |
| 업데이트 설치 도우미 | 앱이 종료된 뒤 업데이트 설치 프로그램을 실행하고 앱을 다시 시작하는 별도 프로그램(화면의 정리 확인 안내에만) | 실행기, 러너 |
