# Control Center 데이터 및 복구

현재 설치의 활성화·상태 기록과 데이터 checkpoint 복원을 검토한다. 새 설치는 네 제품의
저장소 준비와 상태 기록을 확인한 뒤 확정한다. 복원은 선택한 checkpoint와 현재 데이터를
검토하고, native 소유권·generation·상태 검사가 통과한 작업만 적용한다.

이 fixture는 recovery 경로의 제품 소유권·권한·availability를 확인한다. 실제 설치·복원
수용 근거는 Windows의 Suite delivery acceptance와 릴리스 후보 점검에서 기록한다.
