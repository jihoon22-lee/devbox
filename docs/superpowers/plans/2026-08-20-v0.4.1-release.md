**Spec:** `CHANGELOG.md`, `docs/roadmap.md`, `docs/superpowers/specs/2026-08-17-app-interop-design.md`, `docs/superpowers/specs/2026-08-17-wsl-desktop-terminal-design.md`, and GitHub issue #176.

- [ ] **Step 4: Scan all Markdown for contradictory current claims and broken relative links**

Run:

```bash
rg -n 'RC4 코드·자동화 게이트 후보|acceptance 대기|안정판 배포 전 진행|현재는 대상 앱만 실행' -g '*.md'
python3 - <<'PY'
from pathlib import Path
import re

missing = []
for document in Path(".").rglob("*.md"):
    if any(part in {".git", "node_modules"} for part in document.parts):
        continue
    for target in re.findall(r"\[[^\]]+\]\(([^)]+)\)", document.read_text(encoding="utf-8")):
        target = target.split("#", 1)[0].strip()
        if not target or "://" in target or target.startswith(("mailto:", "/")):
            continue
        resolved = (document.parent / target).resolve()
        if not resolved.exists():
            missing.append(f"{document}: {target}")
assert not missing, "\n".join(missing)
PY
```

Expected: no current-state contradiction remains; historical RC changelog entries and historical plans/reports are allowed. Every repository-relative Markdown link resolves.
