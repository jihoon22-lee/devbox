## Evidence layers and retained boundaries

Synthetic fixtures verify deterministic crash/space/permission/journal and geometry branches.
Native hosted Windows verifies compiled binaries, real WebView/IPC/filesystem/process/installer.
CDP composition is not physical Korean IME input, modeled monitor/DPI changes are not a physical
multi-monitor session, and crash recovery fixtures are not an actual OS reboot. These must remain
explicitly labelled in #542's final disposition; no unexecuted physical scenario is counted as PASS.
Pinned v0.7 user-machine evidence is historical and does not establish v0.8 behavior.

Performance measurements keep B01 budgets unchanged, record the same VM identity and report
workload/profile differences. Known failing baseline metrics remain failures in the baseline record.
No local Docker daemon/container/network/firewall mutation is part of acceptance.

## Allowed historical dependencies

- `apps/legacy-v0.7-catalog.json`: source discovery, Manager provenance and baseline fixture identities.
- Owner migration readers: explicit old app-data roots and original SQLite/WebView storage formats.
- `crates/installation-tools` and `crates/launch` metadata readers: bounded read-only old installation
  resolution for diagnostics/cleanup review. Retired product execution is rejected centrally before spawn.
- Retained unregistered domain command adapters/argv parsers: original domain regression contracts;
  new hosts implement direct routes and do not call the legacy executable router.
- `.github/scripts/legacy-v0.7-*.json`, historical manifest/flatten parsers and installed-file reference:
  pinned baseline measurement/migration/removal evidence, never current public build input.
- `docs/history`, dated design/workthrough records and `baselineSourcePath`: historical provenance.

`check-source-cutover.py` enforces the four directories, library-only engines, no old workspace members
or new host calls to the retired executable router. External shortcuts pointing at deleted executables
require explicit user replacement; expired one-time handoffs do not become new authority.
