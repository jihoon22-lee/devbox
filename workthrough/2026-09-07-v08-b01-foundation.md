# v0.8 B01 product foundation

[Draft PR #554](https://github.com/jihoon22-lee/devbox/pull/554) begins the open
v0.8 milestone from `6f811df`. B01/#543, #541/#542 and the milestone remain open;
product migration, final acceptance and stable publication are incomplete.

Four hidden Tauri/React shells consume one validated product catalog and shared
native/React adapters. Native authority is limited to local main-window describe
and bounded route-status requests with session/replay/context validation.
Development copies use distinct runtime namespaces; public selection retains
15 applications. No stable release or tag is produced by this bundle.

The Control Center synthetic harness uses WAL-consistent SQLite backup and a
transactional import mapping journal. It exposes no production migration command.
A 572-entry source inventory tracks pending semantic owner review. The data
inventory classifies 37 preservation groups across all 15 apps, including
WebView2 localStorage, authoritative vault/templates and derived search indexes.

Operation/Problem DTOs preserve native owner/request/revision and distinguish
cancellation, staleness and failure. Rust and TS share six observations; unknown
fields and unverified problem payloads fail closed. Existing Workbench worker
controls remain in place. The feature scaffold generates route/owner metadata,
fixture, documentation and validator registration; a Control Center route is
exercised by the generated fixture. See the [foundation contract](../docs/architecture/v0.8-foundation.md)
for authority/data decisions and outstanding B01 gates.

Windows acceptance uses a cwd-independent Cargo output root and reuses existing
per-image WebView2 policy helpers on the elevated disposable hosted runner. Safe
import/self-test checks preserve release smoke CLI behavior. This follows
[Microsoft's elevated-host override rules](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/security#for-an-elevated-host-app-use-appropriate-override-flags).

polling now tolerates an initial empty document and reports bounded synthetic
probe diagnostics. It must pass actual Windows execution before acceptance.
