# v0.8 B01 product foundation

[Draft PR #554](https://github.com/jihoon22-lee/devbox/pull/554) starts the v0.8
milestone from `6f811df`. B01/#543 and #541/#542 remain open. No merge, release or
stable tag has been produced; product feature migration is still pending.

Four hidden Tauri/React shells consume one catalog and native/React adapters.
Only local main-window describe and bounded route-status commands are exposed.
Requests bind native owner/install/session/context/revision and reject replay.
Public packaging still selects the existing 15 apps. Operation/Problem,
ProjectContext, source-owned AppLink artifact and existing SecretReference
contracts have native/shared fixture consumers; the feature scaffold registers
route, fixture, documentation and validator entries.

The 572-entry baseline inventory records reviewed capability/authority and
registration groups for all 15 apps; every inventoried native command is in its
handler registry. A separate data inventory classifies 37 preservation groups,
including WebView2 localStorage, vault/templates, derived indexes and Runtime
ownership history. None of the pending v0.8 parity entries is marked verified.

Control Center's synthetic migration harness uses WAL-consistent backup,
completed snapshot metadata, a product/install destination namespace and bounded
dry-run mappings/conflicts. Import/validation/cancellation and durable completion
receipts share a DB transaction. Restart, repeat, stale/foreign plans and linked
paths have fixtures. No production importer or renderer path selection is exposed.
See the [foundation contract](../docs/architecture/v0.8-foundation.md) for limits.
