## Source-audit correction

The relocation/worktree audit compared dirty historical worktrees with current reviewed source
instead of treating a squash merge or dirty directory as proof of equivalence. It found two
Workbench preflight safety hunks absent from RC2:

- native Windows directory probes needed to accept only drive/UNC paths while WSL probes accepted
  only POSIX paths; and
- existing path components needed inspection before final-target metadata so a missing descendant
  below a symlink or Windows reparse point could not be classified as ordinary `Missing`.

PR #467 ports only those boundaries into the current hardened implementation. It does not restore
the obsolete worktree wholesale or remove later operation-budget, cancellation, bounded reader,
deadline, and process-tree ownership protections. Required CI run 33201855818 passed all six jobs,
and the correction merged as `9dc237e23717bc294da0ff66d86df1bdce3cb595`.

The focused/full local correction results are recorded in
`workthrough/2026-08-29-workbench-preflight-path-safety.md`: Workbench regressions and lib tests,
clippy, complete workspace Rust test/check, the 19-project frontend build, Workbench frontend
tests, dependency policy, catalog/release-verifier fixtures, format, and diff checks all passed.

RC2 remains immutable for provenance but is not eligible for stable promotion. The correction and
RC3 reset are recorded in issue #176 comments
`5456311189` and `5456666531` without marking unobserved runtime checklist items complete.

## Relocation-ready cleanup contract

After all devbox release work, the user plans to move the WSL distribution from C: to E:, then move
projects from `/mnt/e/projects` to `/home/jihoon/projects` inside the relocated WSL. Cleanup is
therefore part of making the repository small, self-contained, and safe to move; it is not an early
deletion mandate.

- Required source, documentation, decisions, and compact evidence must first be reviewed and
  incorporated into `main`.
- Clean, merged or demonstrably superseded dedicated worktrees and their local/remote branches are
  removable only after equivalence is proven. The required order is worktree remove, worktree
  prune, local branch delete, then confirmed remote branch delete.
- Dirty, unmerged, locked, unknown, active, or host-owned worktrees are inspected and reported before
  any mutation. `.claude/worktrees` is host-owned and is never deleted automatically.
- Reproducible `node_modules`, `dist`, release downloads, runtime scratch, and external build caches
  are removed only when their source/evidence role has ended. RC3 and stable evidence remain until
  compact final evidence is merged.
- The final audit checks tracked and dangling symlinks, runtime configuration, absolute path
  dependencies, registered and orphan worktrees, local/remote branches, open PRs, tags/releases,
  running build/test processes, and C:/E: capacity. Historical path fixtures are documented rather
  than rewritten merely because the repository will move.
- C: free space must remain at least 100GB during the remaining work. WSL sparse-disk compaction is
  intentionally deferred until after the release and user-scheduled relocation.
