# B02 API Studio consolidation

Tracking: #544, master #541, acceptance #542. Implementation remains in progress.

This extraction moves API Playground's six pure protocol modules into
`crates/api-protocols`. Existing native commands re-export and consume the same
implementation; dialogs, DPAPI, network sessions and processes stay in the app.
The newly public library uses a named random-source error and exposes
`MessageBuffer::is_empty`; neither changes runtime outcomes.

The extracted core's 51 tests passed. Subsequent product/native/UI wiring is
being verified in the same B02 worktree and will follow in this PR. Migration,
internal handoffs, Windows integration and final acceptance remain open.
